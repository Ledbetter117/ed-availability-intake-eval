# ED Availability Intake Evaluation

**Built and audited a Python evaluation for extracting structured availability from synthetic calendar images.** The project includes generated reference data, historical results, a typed error audit, a multi-model runner, and tests for failure handling and local-only routes.

The audit corrected a note-mismatch metric that had been described as hallucination, separated prediction and reference denominators, and reported document-level errors alongside cell accuracy. It preserved the original release and the correction history. Later repairs added authenticated loopback support, credential reflection handling, enforced installation checks, and preparation for both original photograph-probe arms.

**Evidence:** 40 synthetic calendars; saved results for two recorded model labels; public per-case and typed-error records; offline and synthetic transport tests; a technical report with a numerical source map.

**Limit:** The work does not establish real-handwriting accuracy, live local-model performance, staffing benefit, or clinical safety. Both photograph-probe endpoints remain unfinished.
